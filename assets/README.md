# 应用图标

`CCCC.svg` 是可编辑的矢量原稿。图标采用与 ApoSwitch 相近的炭灰底座、彩色珐琅面板和浅色浮雕层次，保留 CCCC 的绿色、重叠纸张与对勾。所有图形由 SVG 几何、渐变和滤镜组成，没有嵌入位图、字体或外部资源。

`CCCC.ico` 是从同一份 SVG 导出的 Windows 应用图标，包含 16、20、24、32、40、48、64、96、128 和 256 像素版本。小尺寸使用带透明通道的 32 位 DIB，256 像素使用 PNG 压缩。

构建脚本直接嵌入 ICO；托盘复用程序图标。SVG 只用于编辑和导出，不增加运行时依赖，也不影响提示卡片内的矢量对勾。

调整图标时应同时更新 SVG 与 ICO。版本号与其他程序行为未随本次图标调整改变。
