# CCCC

**让每次复制，都有回应。**

一个为 Windows 做的复制反馈小工具。按下 **Ctrl+C**，一张小卡片告诉你内容已经复制；忍不住再按几次，它也会用计数、弹跳和一点点幽默回应你。

## 多按几次，也有一点性格

> 已复制 → 还在呢 → 真的复制好了 → 千真万确复制好了 → 去粘贴吧

第一次复制，卡片轻轻淡入。第二次、第三次，卡片和计数器一起快速放大、缩回。等确认已经传达，它又安静地淡出。

- **看见刚刚复制的内容。** 简短预览帮你确认文字或文件，连续复制次数也一目了然；预览可以关闭。
- **给日常操作一点手感。** 复制不只有结果，也有及时、轻巧的视觉回应。
- **融入你的桌面。** 跟随 Windows 浅深色模式，柔和的 Acrylic 材质让背景透进卡片；喜欢纯色，也可以关闭高级材质。
- **留在托盘，随时可控。** 可以暂停提示、调整预览，或按需要开启登录自启动。卡片不抢焦点，也不拦住鼠标操作。

## 它为什么诞生

复制是一个频繁、却很安静的动作。因为没有明确的回应，我们往往会在 Ctrl+C 之后，再补上几次 Ctrl+C。

CCCC 想补上这份反馈：让你看见刚刚复制了什么，知道重复的按键也被接住了，然后安心去粘贴。它不保存剪贴板历史，也不上传复制内容，只照顾眼前这一次操作。

## 开始使用

当前仓库从 **v2.4.6** 里程碑源码起步，**本轮尚未提供 Release 下载版**。希望自行体验，可以先阅读[构建指南](docs/building.md)。

构建后运行 `CCCC.exe`，像平时一样复制即可。右键托盘图标，可以找到 **暂停提示、显示内容预览、开机自启动、高级材质**。

适用于 Windows x64，需要 .NET Framework 4.8。无需安装字体，所需字形会内嵌到构建好的程序中。
