# CCCC v2.4.9-preview.1

本次预览版修复了普通卡片的高级材质闪边，以及设置提示与复制反馈内容串用的问题。

## 修复内容

- 修复普通卡片开启高级材质后，连续复制、卡片弹跳时边缘闪烁的问题。该现象在部分 1080P 屏幕和较低刷新率下更容易察觉，浅色和深色模式均可能出现。
- 修复设置提示仍在显示时按下 Ctrl+C，复制次数错误出现在“高级材质已开启”等设置提示上的问题。复制结果到达后，卡片会直接切换为对应的标题、内容预览和计数。

保留现有配色、字体、四倍文字渲染和弹跳节奏。普通卡片与任务栏单行样式切换、内容预览、开机自启动和高级材质开关继续可用。

## 升级与下载

先从托盘退出旧版，再运行新版。沿用现有设置，无需额外安装字体。

- `CCCC-v2.4.9-preview.1.exe`：单文件程序，下载后直接运行。
- `CCCC-v2.4.9-preview.1-portable.zip`：包含同一程序、使用说明和许可说明。
- `CCCC-v2.4.9-preview.1-source.zip`：源码包，自行构建时需要按构建指南准备字体。

适用于 Windows x64，需要 .NET Framework 4.8。

## 已知限制

此版本仍为预览版。任务栏样式的空位检测、天气和左侧按钮避让、自动隐藏及多屏处理仍在完善，可能出现遮挡或回退到任务栏上方。

本次未处理运行时的“未知发布者”安全警告。材质修复已完成本机验证并收到用户试用确认，尚未覆盖所有显卡、缩放比例和刷新率组合。
