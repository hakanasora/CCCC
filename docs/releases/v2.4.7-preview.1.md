# CCCC v2.4.7-preview.1

这是任务栏提示的公开预览版，以第四个任务栏原型为基础，合并至 `main`。普通卡片的外观保持原样，新增可切换的任务栏单行样式。

## 体验内容

- 右键托盘 → **提示样式**，切换“普通卡片”和“任务栏单行”。
- 任务栏胶囊保留复制提示、连续复制计数及弹跳反馈；不显示第二行内容预览。
- 任务栏背景融合沿用已确定的 UI：浅色 `#F0F0F0`、80% 不透明度与 2.35% 弱阴影；深色白色覆盖 6%、无阴影；均无描边。
- 开启“融合任务栏背景”时，透出任务栏自身材质，不再叠加额外模糊；关闭后使用不透明背景。
- 普通卡片继续提供原有四倍文字、内容预览、材质和动画。

## 使用

适用于 Windows x64，需 .NET Framework 4.8。先从托盘退出旧版，再运行 `CCCC.exe`。程序可直接运行，无需安装字体。

预览版沿用独立配置 `%LOCALAPPDATA%\CCCC\settings-taskbar-experiment.txt`，不覆盖稳定版 `settings.txt`，也不迁移或修改真实自启动登记。为避免预览程序替换稳定版的自启动路径，本版暂不提供开机自启动。已用过第四个原型的用户可继续使用原来的预览配置。

想换回稳定版时，先退出预览版，再运行 v2.4.6。

## 已知限制

任务栏 UI 已确定，**空位检测及边缘情况仍在研究中**：

- 目前主要面向主屏底部常显任务栏。
- 尚未取得控件结果时，使用左侧试验位置，可能覆盖天气或左侧按钮；成功探测后再避让已识别控件。
- 控件边界可能变化或不完整，自动避让尚不可靠；空间不足、自动隐藏、其他屏幕等情况可能回退到任务栏上方。
- 真实任务栏层级、跨进程点击穿透、美化工具及全屏应用兼容性尚未完成系统验证。

需要稳定使用时，建议继续使用 v2.4.6，或在本版切回普通卡片。
