# 设置提示与复制反馈交接

2026-11-09，基于普通卡片材质闪边修复继续修改。用户已反馈该材质修复在实际使用中有效。

程序显示“高级材质已开启”等设置提示时，Ctrl+C 的预反馈路径仍会给当前提示写入复制次数，并准备标题动画。真正的复制结果随后到达时，旧设置标题又会在标题渐变期间短暂保留，导致设置文字与复制计数、内容预览串用。

本次复用现有 Feedback.Kind 分类。CopyPressed 遇到 Status 提示时保持当前内容，等待真实结果。Present 收到复制结果时立即替换设置标题。普通复制之间的标题动画、首次显示与重复弹跳保留。没有新增状态字段、设置项、依赖或接口。

修复前的真实 WPF 截图显示“高级材质已开启 ×3”。同一场景修复后，等待结果时没有计数，结果到达后显示复制标题、预览与正确次数。诊断程序使用专用窗口，不写真实剪贴板、配置或自启动。

回归测试先复现 actualCount=1 的设置提示污染。隔离第一处修复后，第二处仍报告 copyResultImmediatelyReplacesStatus，旧标题为“高级材质已开启”。完整修复后的动画检查通过 52 项，另有 44 项质量、128 项任务栏离屏断言通过。新增覆盖四种复制结果，以及状态提示期间的连续按键、结果接管和后续弹跳。

独立审查未发现阻塞问题。设置提示恰好处于入场、淡出或前一次弹跳尚未结束时的交接，没有新增专门的组合测试，不把这些组合称为已单独验证。
