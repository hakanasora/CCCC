CCCC 2.4.6 · 更柔和的淡入淡出与首次复制不弹跳
2026-10-20

以 2.4.5 为基础，本次只调整动画：
1. 整张卡片淡入由 130 ms 改为 200 ms，淡出由 160 ms 改为 220 ms，透明度采用 smoothstep 缓动，起止更柔和。与原来约 210 ms 的弹跳处于相近节奏，不增加入场等待或中途停顿。
2. 卡片隐藏后，键盘首次发起复制只显示实际结果并淡入，不触发卡片或计数器的弹跳。即使复制次数尚未重置，隐藏后重新出现的这一下仍然只淡入。
3. 卡片显示期间，第二次、第三次等重复 Ctrl+C 才触发原来的弹跳。若用户在首个绘制回调前就已发起第二次复制，这次重复按键可以触发弹跳；第一次按键本身不触发。
4. 已显示启动等状态提示时，第一遍 Ctrl+C 也不会弹跳；再次复制才触发。复制计数及提示文案的判断规则不变。
5. 重复复制的放大参数保持原样：卡片峰值 1.06、计数器总峰值 1.18，55 ms 放大、155 ms 缩回。渐出时再次复制，从当前透明度柔和恢复，不跳到完全不透明。

仅调整整张卡片的透明度，主提示文字原有的快速淡出／换字／淡入保持原样。
四倍文字清晰度、字体、计数布局、连续圆角、配色、高级材质开关和资源释放方式均沿用 2.4.5；无新增设置或依赖。

升级时先从托盘退出旧版，再打开 CCCC-v2.4.6.exe，或便携包中的 CCCC.exe。
2.4.5 及更早版本保留，可退出新版后运行旧版回退。本次制作不修改真实用户设置、剪贴板或自启动登记。
如果需要让自启动改为新版路径，请在新版取消后重新勾选“开机自启动”。

只做了编译和本轮淡入淡出／首次与重复按键的轻量检查，未运行大型回归、内存或性能矩阵，也未制作交付截图。
最终节奏与舒适度由你实际使用后确认。Windows x64、.NET Framework 4.8、普通用户权限、单文件便携程序。
